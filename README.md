# Drops — Telegram-бот и мини-приложение

## Запуск

1. Создайте бота через @BotFather и задайте переменную `BOT_TOKEN`.
2. Укажите публичный HTTPS-адрес приложения в `WEBAPP_URL`.
3. Запустите `pip install -r requirements.txt`, затем `python bot.py`.
4. Для сохранения базы данных между перезапусками задайте `DATA_DIR` на постоянный диск.

## Переменные окружения

- `BOT_TOKEN` — токен Telegram-бота.
- `WEBAPP_URL` — адрес мини-приложения с HTTPS.
- `ADMIN_ID` — Telegram ID владельца панели. По умолчанию `618124780`; поменяйте значение, если ваш ID другой. Панель и административные API доступны только этому ID.
- `DATA_DIR` — каталог базы данных (по умолчанию `data`).
- `TON_ADDRESS` — адрес кошелька для пополнения.
- `TONCENTER_KEY` — необязательный ключ Toncenter.
- `ROSTISHKA_LINK` — ссылка для Ростишки 3 (по умолчанию задана ссылка из проекта).
- `PORT` — порт веб-сервера (по умолчанию `8080`).

## Ростишки

- Ростишка 1 устанавливается как аватар в мини-приложении.
- Ростишка 2 начисляет 2 монеты.
- Ростишка 3 открывает Telegram-ссылку.
- Ростишка 4 включает плавающий экран на 5 минут; оставшееся время хранится на сервере и переживает перезаход.
- Ростишка 5 отправляет заявку в админ-панель. После нажатия «Задания» предмет исчезает из инвентаря; администратор может принять заявку, и пользователь получит сообщение от бота.

Обычные призы открываются нажатием в инвентаре: показываются описание и кнопка действия. При получении бот сообщает администратору имя, Telegram ID и приз.
